# Запуск на компьютере администратора

## Если нужен только учёт

Откройте https://yaroslavnasol.ru/dentumlab/ и войдите с выданной почтой и паролем. Счета, материалы, оплата и получение доступны в браузере. Устанавливать Git, Python и модель для этого не требуется.

## Если этот компьютер будет распознавать счета

Нужны интернет, Windows 10 22H2 или Windows 11, 64-разрядная система. Для выбранной Qwen3-14B ориентируйтесь на 32 ГБ оперативной памяти и не менее 25 ГБ свободного места. Это рекомендация для установки, а не гарантия скорости: без подходящей видеокарты разбор может быть заметно медленнее Mac. Меньшую модель автоматически не подставляем: на реальном счёте она ошибалась в суммах.

1. Скачайте код: https://github.com/protoptica/dentumlab/archive/refs/heads/main.zip
2. Распакуйте архив в постоянную папку, например `%USERPROFILE%\DentumLab`. Внутри должны лежать `WINDOWS.md`, `SETUP-WINDOWS.cmd` и папка `worker`. Не запускайте файлы прямо из ZIP.
3. Получите у владельца отдельный файл **worker-config.env** для этого компьютера. Положите его рядом с `WINDOWS.md`. Не отправляйте этот файл в GitHub и не публикуйте его. Это ключ обработчика, а не пароль для сайта.
4. Дважды нажмите **SETUP-WINDOWS.cmd**. Установщик проверит и при необходимости установит Python 3.12, Ollama и Tesseract через Windows Package Manager, загрузит русский и английский OCR, создаст Python-среду и скачает `qwen3:14b`. Загрузка модели — около 9 ГБ; понадобится время. Windows может запросить разрешение на установку программ. Подтвердите только если вы запускаете этот файл из скачанного репозитория.
5. Дождитесь строки **Ready. Run START-WORKER.cmd**. При ошибке окно останется открытым. Исправьте указанную причину и запустите установку снова — повторный запуск предусмотрен.
6. Дважды нажмите **START-WORKER.cmd**. Окно можно свернуть. Закрытие окна останавливает обработчик; сайт и бот продолжат принимать документы.
7. Для запуска после входа в Windows нажмите **ENABLE-AUTOSTART.cmd**. Создаётся ярлык только в автозагрузке текущего пользователя. После этого не перемещайте папку приложения. **DISABLE-AUTOSTART.cmd** удаляет ярлык; текущий обработчик останавливается закрытием его окна.
8. Пришлите один новый тестовый счёт боту. Через `/status` проверьте переход от очереди к обработке и проверке. Откройте счёт на сайте, сверьте строки, фасовку и итог с PDF. Подтверждение выполняет человек.

Командные файлы запускают PowerShell с разрешением выполнения только для этого процесса; системную политику выполнения не меняют.

## Проверка и остановка

- Журнал: `.local\worker-windows.log` в папке приложения. Строка «Задание завершено» означает, что результат записан в общую базу.
- Ollama должна работать, а компьютер не должен спать. Если компьютер выключен или спит, задания остаются в Supabase.
- Mac и Windows могут работать одновременно: задания защищены арендой. Для проверки именно Windows временно остановите обработчик на Mac, затем отправьте тестовый файл. Не выключайте Mac-процесс посреди обработки без необходимости.
- Безопасная проверка установки: повторный запуск `SETUP-WINDOWS.cmd` проверяет подключение, не забирая счёт из очереди.
- Для остановки нажмите Ctrl+C в окне обработчика. Если включён автозапуск, он снова запустится при следующем входе в Windows.

## Если установка не прошла

- Нет `winget`: установите или обновите **App Installer** из Microsoft Store.
- Python не найден после установки: закройте окно и повторите `SETUP-WINDOWS.cmd`.
- Нет прав на установку Tesseract: потребуется администратор Windows. Не отключайте защиту компьютера; попросите установить программу.
- Ollama не отвечает: откройте Ollama из меню «Пуск» и повторите запуск.
- Ошибка подключения к облаку: проверьте интернет и наличие выданного `worker-config.env`. Не подставляйте service_role или Telegram-токен.
- Нет памяти или обработка слишком медленная: оставьте распознавание на Mac; сайт на Windows продолжит работать. Подбор другой модели требует проверки на ваших счетах.
- Неверная сумма распознавания: результат не подтверждается автоматически. Проверьте оригинал и статус; не исправляйте сумму наугад.

## Обновление

Остановите обработчик. Сохраните приватный `worker-config.env` отдельно. Скачайте свежий ZIP из того же репозитория и замените исходники в постоянной папке. Верните приватный файл, выполните `SETUP-WINDOWS.cmd`, затем `START-WORKER.cmd`. Не переносите Python-среду `.venv` с Mac на Windows.

Секреты хранятся локально в `worker/.env`, данные учёта — в Supabase, оригиналы — в Telegram. GitHub содержит только код и инструкции. У каждой установки обработчика должен быть отдельный отзываемый ключ.

Подготовлено и проверено на Mac: Python-обработчик, API подключения, миграции и сборка сайта. Установка Windows и её автозапуск требуют проверки на компьютере администратора; они здесь не запускались.

Официальные сведения: https://docs.ollama.com/windows ; https://github.com/UB-Mannheim/tesseract/wiki ; https://learn.microsoft.com/windows/package-manager/winget/
